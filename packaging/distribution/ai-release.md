## Optional ScreenSort AI package — Windows x64 CPU preview

Contains portable CPython, locked Python libraries, RapidOCR and the pinned Florence-2-base-ft model. No system Python, pip, Docker or NVIDIA GPU is needed. Photographs are processed locally; this download contains no user photographs or application database.

Install using **Pobierz pakiet AI** in ScreenSort 0.2.0, or download the ZIP and use **Wybierz pobrany ZIP**. Do not manually extract it into your database directory. The application verifies the package's exact size and SHA-256 before extraction and activation.

This is the first CPU profile, not a choice of lightweight/heavyweight models yet. OCR and visual descriptions are imperfect; game names, brands and fine-grained categories can be wrong. Human review is required.

The ZIP includes dependency license metadata, third-party notices and the Florence license. SHA256SUMS provides integrity information; it is not a digital publisher signature. Partial downloads must currently be retried from the beginning.
