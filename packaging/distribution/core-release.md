## ScreenSort Windows x64 preview

The Core installer starts the local catalog and private PostgreSQL without installing Python or loading AI models. No Docker, JDK or system Python is required on the user's machine.

To enable analysis, use **Pobierz pakiet AI** inside the application, or **Wybierz pobrany ZIP** for the matching official package. After installation, click **Uruchom AI**. Downloaded packages are checked against the SHA-256 pinned in this app version.

Current AI profile: CPU, RapidOCR and Florence-2-base-ft. Recognition and category/name suggestions are imperfect and require review. Automatic export/moving of originals and alternative model/GPU profiles are not included.

Early preview, currently without Authenticode signing. Back up important application data before upgrading. Do not delete an existing database to fix a startup error.
