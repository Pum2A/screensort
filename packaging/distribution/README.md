# ScreenSort releases

Official distribution files for ScreenSort for Windows x64. This repository contains installers, optional AI packages, checksums and third-party notices, not user photographs or databases.

ScreenSort scans local images and stores a catalog on your computer. Optional OCR and visual descriptions run locally after you install and start the AI package inside the application.

## Preview status

This is an early preview. Category and filename suggestions need human review. No automatic modification of source photographs is performed. GPU profiles and a choice of alternative models are not available yet.

Download only assets from this repository's Releases. The Core installer does not include Python, machine-learning dependencies or model weights. The application checks the exact SHA-256 of its supported AI ZIP before installing it.

The Windows installer is not currently Authenticode-signed. A SHA-256 checksum is an integrity check, not an Authenticode signature. Follow your organization's software policies.

See the attached third-party notices and Florence license. Downloading the AI package contacts GitHub; your photographs are not uploaded to GitHub for analysis.
