# VT323

Font retro PC używany przez ScreenSort. Plik jest dołączony lokalnie: interfejs nie odpytuje Google Fonts ani CDN.

Autor: Peter Hull. Źródło: https://github.com/google/fonts/tree/main/ofl/vt323

`VT323-Regular.ttf` jest rozpowszechniany bez modyfikacji na licencji SIL Open Font License 1.1. Pełna treść i informacja o prawach autorskich są w `frontend/public/VT323-OFL.txt`; Vite kopiuje je także do produkcyjnego `dist`, a Tauri dołącza do aplikacji.
